# BASE 営業自動化パイプライン v1

## 原則
AIは「探す・整理する・下書きする」まで自走。対外送信は本人承認後。

## 流れ
1. 公開情報から候補企業を収集
2. 業種・地域・想定課題で分類
3. BASEで対応できる可能性がある課題だけ抽出
4. 提案仮説を1社1〜2個作る
5. 営業文を下書き
6. 重複・不適切表現・未確認事実をチェック
7. 承認待ち一覧へ追加
8. 本人承認後のみ送信
9. 返信内容を案件ステータスへ反映

## 初期ターゲット
オンライン完結しやすく、定型PC作業が多い小規模事業者・店舗・福祉関連事業所。

## 初期オファー
「業務自動化ミニパック 33,000円〜」を入口にする。いきなり大規模DXを提案しない。

## 禁止
- 無差別大量送信
- 実在企業について未確認の問題を断定
- 補助金採択・売上向上・削減率などの保証
- 本人承認なしのメール/DM送信
- 前職人脈・取引先への依存を前提にしたリスト作成

## 管理項目
会社名 / URL / 業種 / 地域 / 公開連絡先 / 課題仮説 / 提案候補 / 優先度 / 下書き / 承認状態 / 送信日 / 返信 / 次アクション
