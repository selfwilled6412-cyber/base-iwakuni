# BASE 営業候補スコアリング v1

## 目的
公開情報だけを使い、無差別営業を避けながら「業務自動化ミニパック」と相性が良さそうな候補を優先順位付けする。

## 100点満点
- 定型PC作業が多そうな業種: 0〜25
- 問い合わせ/予約/申込などWeb導線がある: 0〜15
- 小規模事業者・店舗・福祉関連など初期対象に合う: 0〜20
- 公開情報から具体的な改善仮説を作れる: 0〜20
- オンライン相談で完結しやすい: 0〜10
- BASEの既存サービスとの関連性: 0〜10

## 優先度
- A: 70点以上。提案文の下書き作成候補
- B: 50〜69点。情報を追加確認
- C: 49点以下。原則保留

## 必須チェック
- 公開情報だけを使う
- 実在企業の問題を断定しない
- 「〜の可能性」「もし〜なら」の仮説表現にする
- 前職の既存取引先・人脈を主軸にしない
- 個人情報を収集しない
- 営業文の外部送信は本人承認まで行わない

## 承認待ち一覧の列
会社名 / 公式URL / 業種 / 地域 / 公開問い合わせ先 / スコア / 根拠 / 課題仮説 / 提案候補 / 営業文下書き / 承認状態 / 備考
