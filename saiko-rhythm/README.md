# SAIKO BEAT RUSH — サイ校オリジナル音ゲー（試作版）

サイ校プロジェクト岩国で試遊・フィードバックを集めるための、ブラウザだけで動くリズムゲームです。

- URL: https://selfwilled6412-cyber.github.io/base-iwakuni/saiko-rhythm/
- 初期バージョン: 2026-10-29
- ゲーム音源: Web Audio APIのオシレーター・ノイズによる独自の手続き的合成。第三者の市販楽曲／音声ファイルは組み込まれていません。
- 曲: STARLIGHT DRIVE（116 BPM）、COLOR JUMP（132 BPM）、NEON BREAKER（152 BPM）
- それぞれ約32〜41秒、やさしい／ふつう／むずかしい
- ひとり: D/F/J/K、初級では中央2レーンのみ
- 2人対戦: A/S vs K/L（2人の譜面ノート数は同じ）
- 4人ビートリレー: D/F/J/K、1人1レーン（全員のノート数は同じ）
- スマホ・タブレットでは画面下部のタッチボタンを使用（横向き推奨）
- PERFECT/GREAT/GOOD/MISS、得点、コンボ、端末内だけの自己ベスト、音量、判定タイミング調整、演出控えめ、一時停止。
- アカウント・氏名・顔写真なし。得点はlocalStorageのみ。ネットランキングや課金は未実装。

## NEW: BEAT STUDIO（自分の曲を使って譜面を作る・試作品）

- URL: https://selfwilled6412-cyber.github.io/base-iwakuni/saiko-rhythm/studio.html
- **自分が利用権限を持つ音楽ファイル**（MP3/WAV/M4A等・端末が再生できる形式・最大50MB/10分）を端末内で選択。
- BPM/開始拍/難易度を設定し、リズムの下書きを生成。短いファイルでは音の強弱ピークも補助的に利用。
- 8秒単位の4レーン編集、マスをタップして追加/削除、1手Undo、音源プレビュー、D/F/J/Kで音ゲー形式のテストプレイ、PERFECT/GREAT/GOOD/MISS判定。
- JSON譜面の書き出し・読み込み、**ユーザーの明示操作による**ブラウザへの一時保存に対応。JSONには音声データを含めない。
- 音源ファイルはアプリのサーバーに送信しません。ページ再読み込み後の再生には音源ファイルを再度選択してください。
- 既存の3曲のゲームは引き続き独立して利用可能。BEAT STUDIOは録音した音楽・購入楽曲の合法利用を自動保証しません。YouTubeから音声を抽出する機能はありません。
- このツールの自動譜面は「AIによる完全解析」ではなくBPM配置と簡易ピーク検出の下書きです。商用販売には引き続き品質確認が必要です。

**詳細:** [PRODUCT_ROADMAP.md](PRODUCT_ROADMAP.md) に、施設販売版・個人版の商用化ゲート、音楽権利処理、現場評価の段階的計画を記載しています。

## 2026-10-29 音声と譜面の改修

- 実際の音で自動譜面を作るモードを追加：権利のあるMP3/WAV等を端末内でだけデコードし、音量変化とアタックから候補時刻を抽出。等間隔BPMノーツを使わず時刻を基に譜面を生成。無音で適当なノーツを生成しない。
- YouTube版では同じ曲の手元の音声ファイルを読み込めば、その解析結果を公式プレーヤーの再生時刻に沿って描画。イントロ等の時差を−10〜＋10秒で補正可能。YouTubeの音源自体は取得・分析しないため同じ録音／ミックスが必要。
- 公式埋め込みプレーヤーの上にノーツを重ねない（YouTube規定）。大きな独立レーンでプレイでき、スマホは動画を固定。動画のすぐ下にも拍の記録ボタンを追加。
- YouTube版の「BPMだけで仮譜面」は曲を解析しない低精度モード。
- BEAT STUDIOも音源アタック時刻で譜面を作る方式に変更。音の変化が小さい曲は検出しにくく、手動の譜面編集が必要な場合がある。
- ほかの7系統（冒険、キッズ、ひとりアーケード、パーティー、カード、脱出ゲーム2系統）に共有の操作音・成功／失敗音・ON/OFFボタンを追加。自動BGMや既存曲の無断利用は追加していない。
- 音解析と効果音の自動テストをCIに追加。実機での音のタイミングと音量は未検証。

## NEW: BEAT RUSH × YouTube（無料・実験モード）

- URL: https://selfwilled6412-cyber.github.io/base-iwakuni/saiko-rhythm/youtube.html
- YouTubeの一般公開動画URL（watch / youtu.be / shorts / embedなど）を入力すると、**YouTube公式IFrameプレーヤーを可視状態のまま**動画を読み込める。
- 音ゲーの譜面は **手入力BPM・リズム開始位置・難易度** から制作する決定的な下書き。動画音声の抽出、ダウンロード、解析、保存、YouTube広告スキップは一切しない。
- テンポが不明な場合は動画の拍に合わせて「BPMをタップ測定」を4回以上押す。音声を取り込まずにBPMを推定できる。
- **2026-10-29 改善**: 「🔴 記録開始」を押して実際に流れる曲に合わせて「🥁 ビートを刻む」を連打し、「記録終了」。YouTubeの再生時刻を個別に記録した譜面が作られる。スペースキー、D/F/J/Kの各レーン記録にも対応。4拍以上で譜面生成し、記録を端末内localStorageへ動画IDごとに保存・再利用（音声データは保存しない）。
- **視認性改善**: 明るい大きなネオンノーツ、明瞭な判定ライン、レーン配色、落下速度の切り替え。YouTubeプレーヤーに重なる描画は公式規定により行わず、PCは左右一体レイアウト、スマホは動画直下に高コントラストの独立レーン。
- **重要な限界**: 音声の自動解析や楽曲からの完全自動譜面生成はYouTube IFrame APIでは実装していない。手動BPMで作る「仮譜面」は音楽の細かいリズムに一致しない。記録モードの譜面は利用者が音を聞いてタップした部分のみ同期する。ゲーム利用権利の確認は必須。

- プレーヤーの `getCurrentTime()` と `onStateChange` を用い、別領域の4レーンにノーツを表示して採点。動画の停止・読み込み中は譜面も停止。ジャンプしたら得点を初期化する。
- YouTube側の標準動画・広告・音量・字幕・設定・リンクを操作可能なまま残す。背後に隠した動画から音だけを利用したり、視聴を有料で制限する機能はない。
- **サイ校内の試作のみ。利用許諾済み動画で試すこと**。埋め込みが許可された5秒〜10分の通常動画が対象。許諾がないYouTubeの楽曲を音ゲーで利用し販売できるとは断言しない。
- 不具合例：動画の埋め込み制限、広告による遅延、通信バッファリング、端末による判定タイミング差。YouTube側の制約は回避しない。

## サイ校での試遊手順

1. PCでChromeを開き、対象画面・スピーカー・音量を確認する。端末により音声出力の遅延が異なる。
2. まず「やさしい」ひとり用で体験する。画面下の判定ラインに音符が来たタイミングでタップ。
3. 2人対戦はキーボードの左右を2人で分担する。4人モードは各自1つのキーを担当。
4. スマホ横向き・外部モニター・タッチ入力でも確認する。
5. 操作性、聴き取りやすさ、音の好み、端末間の判定ズレ、疲労・光刺激について観察し、任意でフィードバックを収集する。個人を識別する情報の記録は不要。

## 注意・未完成の事項

- Web Audioの合成デモであり、プロ制作のマスタリング済み楽曲や外部MP3音源を使うものではありません。すべての端末の低遅延を保証するものではありません。
- 自動テストでは譜面の公平性とオーディオ時計／操作判定を検証していますが、実機の聴感・タッチ遅延・アクセシビリティは現場確認が必要です。
- 外部サイトから読み込んでいるサイ校ロゴとルミ画像は、本試作の表示用です。別法人による商品販売や素材の二次利用権を取得したとは意味しません。
- 株式会社BASE等で販売する場合、サイ校運営法人との権利関係、既存デザイン・キャラクターの許諾、音源制作契約・著作権、アクセシビリティ、プライバシーポリシー・特商法表記などを先に整理してください。
- 市やeスポーツ大会の公式ゲーム・公認作品ではありません。
