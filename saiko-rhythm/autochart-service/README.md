# SAIKO BEAT：URLから自動譜面（非公開プロトタイプ）

## 目的
YouTubeの動画URLを入力するだけで自動採譜し、元のYouTube公式プレーヤーの再生時刻に合わせてノーツを降らせる。利用者にMP3や譜面の準備を求めない。

## 現状
**コードの試作段階。一般公開・サーバー配信はしていない。** GitHub Pagesだけでは yt-dlp や FFmpeg を動かせないため、別の常時稼働サーバーが必要。公開サーバーの契約、料金発生、ドメイン設定は行っていない。最新のYouTube実動画でダウンロード・解析に成功したことも未確認。

## フロー
- ブラウザから動画ID（11文字）だけを解析サーバーへ送る
- サーバー上の yt-dlp で取得可能な音声ストリームを一時ファイルへ取り込み、FFmpegでPCMへ変換
- numpyでスペクトル差分（音の立ち上がり）からノーツ時刻を推定
- `{video_id, duration, notes:[{t,lane}]}` のJSONだけ返す
- サーバーの一時ファイルは処理終了時に削除する。音声そのものはブラウザへ渡さない
- YouTubeの動画は公式プレーヤーのまま。音ズレは既存の判定補正を使用

解析精度は**初期段階**。曲によっては歌声や打楽器以外の音も検出し、完全一致しない。実用化には譜面品質と再生遅延の実機測定が必要。

## ローカル開発（Windows、Python 3.11以上）
1. Python、FFmpeg（PATHを設定）をインストール
2. `cd saiko-rhythm/autochart-service`
3. `python -m venv .venv`、 `.venv\\Scripts\\activate`
4. `pip install -r requirements.txt`
5. `python app.py` （127.0.0.1:8766 のみ）
6. 開発版画面をローカルHTTPサーバーまたはHTTPSの接続元から開き、「詳細」に `http://127.0.0.1:8766` を設定（実機スマホからPC内ローカルアドレスはそのままでは使えない）

**公開環境で使う場合はHTTPS + 認証 + リクエスト制限 + サーバー費用の確認が必要。** `SAIKO_CHART_BIND=0.0.0.0` を設定して公開する場合、`SAIKO_CHART_API_KEY` がないと起動を拒否する。ブラウザへ公開したキーは秘密を保てないため、一般公開では別途セッション認証とバックエンド中継を設計すること。

## 利用規約・権利
YouTubeの公式IFrame APIから生の音声は取得できない。一方、yt-dlp等による外部取得は技術的に可能な動画もあるが、**YouTubeの規約や作品の権利の問題が消えるわけではない**。YouTubeの仕様変更、動画の制限、地域制限、DRM等で処理に失敗する場合がある。DRM解除や有料コンテンツの保護回避は実装しない。サービスとして公開・販売する前に利用条件と権利を確認する。
