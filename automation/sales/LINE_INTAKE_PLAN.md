# LINE相談 自動取込プラン

## 目的
SNS・WebからLINEへ来た「自動化相談」を、公開GitHubへ個人情報を残さず営業パイプラインへ渡す。

## 推奨フロー

LINE公式アカウント
→ Messaging API Webhook
→ 非公開の受信処理
→ Google Sheets「BASE AI営業｜見込み客・相談管理」へ保存
→ `lead_qualifier.py` 相当の優先度判定
→ ヒアリング不足項目を抽出
→ `proposal_builder.py` 相当の提案骨子を作成
→ 人が確認
→ LINE返信・見積り

## 保存する項目
- 受付日時
- 会社・店舗名（判明時のみ）
- 担当者名（判明時のみ）
- LINE userId（非公開保存のみ）
- 相談本文
- スコア / 優先度
- 課題
- 希望時期
- 予算感
- 利用中ツール
- 次アクション
- 見積状況 / 成約状況

## GitHubへ保存しないもの
- LINE userId
- 氏名
- 電話番号
- メールアドレス
- 実相談本文
- 顧客固有の業務情報

## 接続時に必要なもの
- LINE公式アカウントのMessaging API有効化
- Channel secret
- Channel access token
- Webhook URL

Channel secret / access token はGitHubのコードへ直書きせず、実行環境のSecretへ保存する。

## 自動返信ポリシー
初期段階では外部返信を完全自動にしない。

1. 受信・保存・優先度判定は自動
2. 返信案・確認質問は自動生成
3. 人が承認した返信だけ送信
4. 定型FAQで安全性を確認できたものから段階的に自動返信へ移行

## 最初の受信キーワード
`自動化相談`

キーワードが届いた場合は、最初に以下を確認する返信案を作る。

- いちばん時間や手間がかかっている作業
- 現在使っているツール
- その作業の頻度

価格は最初から確定せず、「業務自動化ミニパック 33,000円〜。内容確認後に個別見積り」とする。
