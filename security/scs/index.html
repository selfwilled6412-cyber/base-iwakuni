SCS EVALUATION

SCS評価制度とは？

企業のサイバーセキュリティ対策を、共通の基準で評価して「★」で示す国の制度です。★3と★4は2027年3月頃の運用開始予定。制度自体は任意ですが、取引先から確認を求められる可能性があります。

★3 / 基本的な対策の確認

まずは守る基礎を整える

企業自身が評価し、制度の要件を満たすセキュリティ専門家が確認。経営層の宣誓を経て登録を申請します。

★4 / より高度な水準

第三者評価と技術検証

指定評価機関が書類や現場を評価し、技術的な検証も行う仕組みです。★3の事前取得が必須という関係ではありません。

※特定の製品を購入すれば★が取得できる制度ではありません。BASEは準備・改善の支援を行い、正式な確認・審査は制度上の専門家・評価機関が担います。制度の詳細・時期は変更される場合があります。

FIRST CHECK

詳しい知識がなくても大丈夫。「分からない」を整理するところから始めます。

OUR APPROACH

BASEが「社外のセキュリティ担当」として伴走。
